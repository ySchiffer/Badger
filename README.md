  Utilitario leve em C# (Windows Forms) para farm de tempo de jogo.
========================================================================

> O QUE O PROGRAMA FAZ?
------------------------------------------------------------------------
O Badger é um utilitário leve desenvolvido para farmar de forma simples e 
leve a nova badge de tempo de jogo no Discord. Ele foi feito especialmente 
para usuários cujos tempos de jogo acabam sendo lidos erroneamente pelo 
Discord (geralmente registrando muito menos horas do que o tempo real 
jogado com o aplicativo aberto).


> COMO FUNCIONA?
------------------------------------------------------------------------
1. Modo de Operacao: O programa mimetiza de forma discreta a atividade 
   de um jogo em segundo plano, garantindo a leitura correta do seu tempo 
   ativo no Discord.
2. Bandeja do Sistema: Roda discretamente na System Tray, com suporte a 
   minimizar ao fechar e iniciar automaticamente com o Windows.
3. Instalacao Limpa: Possui suporte nativo a argumentos de linha de 
   comando (--install, --uninstall) e instalador dedicado.
